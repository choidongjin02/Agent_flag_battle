# SDK로 확인할 경계 사례

| 사례 | 판정/근거 |
|---|---|
| INIT MAP 형식 | `serialize_init`은 15줄 모두 `MAP <row>`로 출력한다. 가상 단독 MAP 형식을 기준으로 만들지 않는다. |
| 자원 부족 건물 다음 후보 | `step_capture`는 해당 건물을 건너뛰고 계속한다. |
| TELE 5명 초과 | `step_move`가 요청·잔여 인원·5명 중 최소로 제한한다. |
| TELE 자기 역→동일 역 | 무효이며 횟수 미소모. |
| PRIORITY 비정수 토큰 | 파서에서 줄 전체 무효. 숫자이지만 건물이 아닌 좌표는 후보 순서에서 제외. |
| 광장 초기 −1 | `serialize_turn` 공개 집합이 비면 −1. 봇은 규칙으로 3을 추론 가능. |
| N1 | 직전 전투 또는 점령 중 소유→중립 표시. 본인 행동으로도 발생한다. |
| MAP 재현 | 제공 `mapgen`과 설정으로 동일 시드 재현. 근사 생성기를 사용할 이유가 없다. |
| MOVE 먼저 출력, SPAWN 나중 출력 | 생산이 먼저 처리된다. builder의 호출 순서와 엔진 단계 순서를 혼동하지 않는다. |
| 도착 셀에 두 번째 MOVE | 원래 그 셀에 남아 있던 인원만 이동 가능. 앞선 도착 인원만 있다면 0명. |
| MOVE2 경유 전투·시야 | 둘 다 없음. 경유 장애물은 명령 무효. |
| 명시적 본진 SPAWN | 무효. 소유 병원 좌표만 허용. |
| F 없는 적 소유 건물에 내 W만 | 소유권 변화 없음. |
| W 동수, 양측 F | W 상쇄 후 경합. 수비 F가 살아 있어 깃발도 유지. |
| W 우세+공격 F, 수비 F 있음 | 수비 F 제거로 중립화 후 비용을 낼 수 있으면 당일 탈취. |
| 빈 적 건물+공격 F | 이번 턴 중립화, 다음 턴 이후 점령. |
| HALL 당일 확보 | 그 턴 수입에는 미반영. 전투로 잃었다면 해당 턴 수입에서 제외. |
| LIBRARY 점령 단계 도중 획득/상실 | 진입 시 보유 여부로 고정. 전투 단계 상실은 할인 제거. |
| DEPOT | 팀별 최초 1회; 후지급; 상한 40; 다른 건물의 당일 점령 재원 불가. |
| 마지막 턴 전량 생산 | 점령 총비용이 수입보다 크면 점수 손실 가능. 점령 예산을 먼저 검증. |
| 본진의 적 W | 생산 F도 탈출 이동하면 본진 전투를 피한다. “생산하면 반드시 죽음”이 아님. |

F 여러 명은 점령 속도를 높이지 않지만 전략적 예비 인원 가치는 상황에 따라 다르다. 정찰이나 경로 탐색 휴리스틱을 규칙적 필수 조건으로 표현하지 않는다. 셀별 최악 위협 합계는 적의 동시 실현 가능한 배치와 다르다.
